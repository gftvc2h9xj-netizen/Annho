# 🎮 数字猜谜游戏 (Number Guessing Game)

一个简单有趣的Python小游戏，考验你的猜数字技能！

## 📋 游戏规则

1. 计算机会随机生成一个1-100之间的数字
2. 你有10次机会来猜测这个数字
3. 每次猜测后，游戏会告诉你：
   - 如果你的猜测太高或太低
   - 还剩多少次机会
4. 猜对就赢了！如果用完10次机会还没猜对，游戏结束

## 🚀 如何运行

### 前置要求
- Python 3.6+

### 安装和运行

```bash
# 克隆仓库
git clone https://github.com/gftvc2h9xj-netizen/Annho.git
cd Annho

# 运行游戏
python game.py
```
